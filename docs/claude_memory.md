## 大问题总结

### 1. Agent 已具备基础任务分解，编排能力仍待深化

当前 ReAct 循环可工作（DeepSeek 能自主判断"文档缺依据时转联网搜索"），但：
- expert可将复杂目标拆成最多10项线性任务，顺序执行并综合汇总；支持整体重规划1次和每任务局部调整1次
- expert classify已支持展示模型原生的简短决策理由；fast无classify，因此不展示理由
- 当前仅线性任务链，不支持DAG依赖图和并行执行，真实2任务搜索+汇总耗时86.21秒
  - expert的generate_file可生成Markdown/TXT/PDF/DOCX；convert_document已接入对话意图，仅允许转换当前session已上传且owner匹配的附件
- reflect 会误判重复 search_web，靠代码层 tool_call_history 拦截兜底
- ReAct仅保留在document路径；普通chat和search均单轮respond，避免重复联网搜索放大延迟
- DeepSeek首次超时、429限流、连接失败或HTTP 5xx会在当前请求state上打开熔断：跳过可选重排、改写、反思与输出观察，仅保留一次最终回答机会；三类故障使用不同原因码，400/401/403/422及参数/审核拒绝不熔断；所有模型阶段受同一`complex_deadline`约束，不改变`EXPERT_COMPLEX_TIMEOUT`数值
- 文档路径只有在多条高质量候选、重排成功且分数明显越过阈值时才视为本地证据充分并跳过联网；单条0.579召回仍按证据不足继续联网，避免F44优化牺牲答案质量
- 当前请求带`attachment_ids`时，expert分类通过结构化附件信号优先选择当前附件直答，fast将附件正文作为独立上下文直接回答；仅转换请求进入`convert_document`。无附件时知识库`search_documents/list_documents`行为保持不变，document低置信度附件fallback继续保留。

  - **指挥师补的两处**：⑴ **表格缺一格**——`3=是`但联网失败时会回落到模型自身知识，那时必须补免责标注，不能沿用「有工具调用故不赘述」；⑵ **第2轴判错的代价不对称**：把内部问题误判为「公开」会让模型编造内部事实（最坏），把公开问题误判为「非公开」只是多拒答一次，因此prompt须写死**吃不准时一律判非公开**。
  - ⚠️ **免责说明必须进回答正文，不能只放执行动态**：实测`zhitian_app/lib/`对`tool_status`/`request_status`**零处理**（只有`web_client/js/api.js`处理），只放执行动态会让Flutter桌面端用户完全看不到提示；且从网页复制走的答案不带旁注。**已定（2026-08-29用户确认，不是待议建议）：正文首句放一行免责说明，执行动态另放详细分类结果，二者并存。** 理由是正文那句会跟着答案走到任何地方——Flutter、复制粘贴、截图都在，而执行动态只有网页端渲染。实施时不得改成「只放执行动态」。
  - ⚠️ **不得放宽的边界**：只有知识库**完全没有可用证据**时才兜底；**部分命中但不足不得兜底**。现有prompt「不得引入片段之外的自身知识来补充、替换、完善或纠正片段内容」的约束必须保留，否则会出现「知识库有三条不完整片段，模型用自身知识补全」，而补进去的内容可能与企业实际规定不符——比完全不答更危险。
  - 用户补充：组织内部事务理论上不会放进知识库，但`2=否→不回答`这条规则仍保留。
> 「按角色限流配置」与「文档调用量统计」均已于2026-08-02实现，不再等待启动。后续出现新的“设计已确认但尚未排期”事项时再在此登记；现阶段不向Phase A/B/C追加执行项。

- **Agent对话回答准确性与效率验证**（2026-08-28登记，尚未排期）。目标是回答「答得准不准、快不快」，而不是「链路通不通」——后者已由本机容器的5份verified文档与382条向量证明。**与既有待评估项「熔断后降级路径产出的回答质量」是同一件事**，应合并为一轮，不要分开排。
  - **难点不在执行，在评判标准**：必须先定义拿什么当基准答案，否则跑完只能得到一句主观感受、无法证伪，也无法在后续版本间做纵向对比。设计确认前不拆成执行指令。
  - **现成语料**：本机具名卷已有5份verified文档，覆盖md/pptx/pdf/docx/txt五种格式且均为法律主题，适合作为构造基准问答集的起点；但该卷是本机环境，构造出的题集应随仓库留存而不是只存在于卷里。
  - **成本**：会产生多次真实付费模型调用（fast与expert都要覆盖），须刻意安排、一次测准，不能反复试。
