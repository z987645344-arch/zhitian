# 独立转换镜像的系统包实测清单

本机隔离构建 `zhitian-api:phase3` 与 `zhitian-converter:phase3`，用 `dpkg-query -W` 读取实际安装包：API 88 个，转换服务 257 个；两者共有 88 个，以下 169 个只在转换服务。与既有本机 `zhitian-api:py312-check` 镜像相比，API同样移除了这169个包；该旧镜像是本机验证镜像，不把它当成生产当前镜像的证据。

API仍包含Python wheel捆绑库：lxml的libxml2为2.14.6，Pillow的libtiff为4.7.1；Python标准库pyexpat报告expat_2.8.5。系统包分离不代表这些解析库消失；PDF、图片和原生DOCX路径仍需原有质量、页数、像素和可终止进程保护。

本机Trivy原始报告：API 11个不重复高危/严重CVE（47条包记录），转换镜像29个（76条记录），并集32个，FixedVersion均为空。单一例外源仅增加images范围：3条API专有、21条转换专有、8条共同基础层；作用包、到期日和规则未放宽。两份报告联合失效检查通过，远程CI仍须用户推送后确认。
