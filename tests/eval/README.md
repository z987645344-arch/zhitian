## 题目契约

`questions.json` 共57个题目单元：单点事实22、跨文档/多跳10、拒答10、部分命中5、多轮5组、公开常识加备注5。多轮分别3或4轮，展开后总计69轮。拒答按内部事务5题、公开常识5题划分。原有50个题目单元保留，修订2新增S21、S22及U01至U05。

- `question`：单轮字符串；多轮为按顺序发送的字符串列表。
- `expected_behavior`：answer/refuse/partial/answer_with_note。
- `expected_points`：事实与约束，不要求照抄措辞；算术题允许计算，但不允许补造输入。
- `forbidden`：禁止被当成事实或建议肯定输出的内容；在否定、纠错或风险说明中引用该词不应机械判错。
- `expected_sources`：相对于`corpus/`的文件名。是支持正确结论的来源，不要求固定引用编号或完整排序。允许引用确实包含同一事实的其他语料，但不能用它替代缺失的跨文档证据。
- `supporting_evidence`：对应来源、条目编号、可核对原文。不是答案模板。
- 拒答题来源为空，不能给不存在的答案伪造引文；缺失是对整套固定语料的判定，不是某一段落的事实。
- `public_with_note`：问题不限定知识库范围；所问事实不在固定语料中，但可由无需联网的公开常识回答。必须答出事实并明确说明来自通用知识、不是本知识库或公司资料；来源为空，不得伪造公司文档引用。与R06至R10限定依据公司知识库的拒答题区分，不能统一按拒答处理。
- `known_issue: docx_table_not_extracted`：S21、S22的事实仅在`03_shipping.docx`的D03-T01附加包装服务表中，正文不重复。`supporting_evidence.source_location=docx_table`标明人工可核对的表格证据；当前读取器只读取paragraphs，表格证据不会进入切片。期望行为仍为answer，让基线如实暴露读取缺陷，不因当前实现缺陷将正确答案改成refuse。
- 部分命中题用`unanswerable_points`标明缺失部分，回答须明确无法确认，不能用自身知识补齐。
- 多轮题的`expected_points`考查最后一轮；`turn_checks`记录每轮检查点。订单号、时间与诉求来自本组用户陈述；它们不是知识库或真实订单查询结果。仅制度结论需要文档引用。
- 每个题目/多轮组应使用独立会话；组内保留历史。不得将别组的演练订单事实带入本组。
